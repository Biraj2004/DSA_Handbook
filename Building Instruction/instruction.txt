LaTeX formatting (always apply):

Math in Markdown: use $...$ for inline and $$...$$ for display math; avoid \[...\] or other delimiters; prefer single-line expressions for cleanliness.
Avoid \text and unnecessary backslashes in LaTeX math notation.
Always include \setlength{\parindent}{0pt} and \setlength{\parskip}{8pt} (or 6pt in exam style) in LaTeX reports.
Use \usepackage[a4paper, margin=0.8in]{geometry}.
Table & counts must match the column spec exactly; no extra &.
TikZ: load all required libraries, define nodes before referencing, use strictly light tints only — myred!10, myblue!10, mygreen!10, gray!15; never solid or dark fills (!50 and above, or bare color names); text inside nodes must always be readable.
Code block style: background RGB(246,248,250) (GitHub light gray); comment color RGB(106,153,85) italic (GitHub green); subtle single-frame border RGB(208,215,222); never dark code backgrounds.

Always add subtle "Biraj" branding — small footer or watermark credit such as "© Biraj" or "Biraj's Notes" in a muted color, unobtrusive but present on every page.

LaTeX font and compilation:

Use XeLaTeX (not pdflatex) for PDF generation.
Fonts: \setmainfont{TeX Gyre Pagella}, \setmonofont[Scale=0.88]{TeX Gyre Cursor}, \setmathfont{Latin Modern Math}.
For Overleaf .tex source specifically: \setmainfont{Calibri}.
Always deliver both .tex source and compiled .pdf.
