02

LaTeX Formatting

Math Inline: $...$   Display: $$...$$
Never use \[...\]. Avoid \text{} and unnecessary backslashes. Prefer single-line expressions.
Page setup \setlength{\parindent}{0pt}   \setlength{\parskip}{8pt} (6pt for exam style)
\usepackage[a4paper, margin=0.8in]{geometry}
Tables Column count must match spec exactly — no extra &.
Global: \arraystretch=1.35, \tabcolsep=7pt.
Primitive types table: use !{\color{black!30}\vrule} column separators between all 5 columns.
TikZ Load all required libraries. Define nodes before use.
Fills: strictly light tints — max !10. Never !50+ or bare color names. Text inside nodes must always be readable.
Code blocks Background RGB(246,248,250) (GitHub light gray).
Comments RGB(106,153,85) italic (GitHub green).
Border RGB(208,215,222), single frame. Never dark backgrounds.
tcolorbox gap \tcbset{before skip=14pt, after skip=14pt} — uniform gap between all boxes.
Branding Small muted footer or watermark — "© Biraj" or "Biraj's Notes" — on every page. Unobtrusive but always present.

05

Table of Contents (tocloft)

Load order Load tocloft after color definitions, hyperref last.
Heading color "Contents" title: myred only via \cfttoctitlefont.
Entry colors \cftchapfont → myblue bold
\cftsecfont → myteal
\cftsubsecfont → mysteelblue small
Rules TOC rules: black, not colored. Chapter page numbers: myblue bold.
